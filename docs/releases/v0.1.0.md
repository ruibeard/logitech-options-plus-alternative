# MX Mouse v0.1.0 — experimental

Small native macOS settings app with a separate C mouse helper.

- Configure five buttons, wheel speed/direction, wheel modes, and pointer DPI.
- Autosave, optional start at login, and supported global Options+ imports.
- Thumb button defaults to native behavior. Existing saved bindings are preserved.
- Settings exits completely when closed.

## Download and install

**Apple Silicon (arm64), macOS 13 or later.** Download `MX-Mouse-v0.1.0-macos-arm64.zip`, unzip, and drag MX Mouse Settings into Applications.

This build is **development-signed and not notarized**. macOS may block opening it; if you trust this release, use System Settings → Privacy & Security → Open Anyway, then follow the prompts. Click Set Up… in the app to grant MX Mouse Helper Input Monitoring and Accessibility access. Quit competing mouse controllers first.

## Supported hardware and testing

Only **MX Master 3 for Mac (046d:b023), direct Bluetooth** is implemented. Other models and receivers are unsupported. Connected-mouse behavior, reconnect, and sleep/wake still need hardware verification.

Automated parser, configuration, device-registry, Options+ importer, and installer regression checks pass. Bundle signatures are checked after extracting the release ZIP. These checks do not replace hardware testing.

The helper measured **4.3 MB** (Activity Monitor) with an MX Master 3 for Mac connected over Bluetooth. Settings uses about 29 MB while open and exits when closed.

The release includes settings recovery, handshake retry on settings reload/system wake, installer replacement fixes, and removal of unused UI state. No App Store or notarization submission is involved.

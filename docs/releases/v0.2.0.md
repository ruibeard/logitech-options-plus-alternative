# MX Mouse v0.2.0 — More mice, one small helper

## New

- One native helper manages multiple compatible Logitech mice, including separate paired slots on a receiver. Each mouse has its own settings and connection state.
- Feature and button discovery replaces the two-model admission list. Settings shows the controls reported by the mouse, including extra buttons and M705 variants with different layouts.
- Bolt and additional Unifying-compatible receiver definitions, including selected Nano and Lightspeed transports. Receiver discovery does not guarantee every paired device supports the implemented features.
- Independent MX Master 4 gesture-button and Haptic-panel bindings when temporary button diversion is supported. Haptic feedback and raw-XY gestures are not implemented.
- Device selection, a generic control list for additional models, and per-device profiles that preserve existing global defaults.

## Fixed

- Receiver mice that report no serial over HID++ (such as the M705 `101b`) no longer stay stuck on "Receiver pairing changed". A receiver mouse is now identified only by its receiver pairing serial.
- A mouse with a new ID (new receiver, re-pairing or older profile key) uses the saved profile of the same model automatically.
- Wider device sidebar with wrapped model names, aligned connection and battery details, and a restored previous-pairings toggle. Historical connections for a listed model no longer appear as extra devices; separate current mice keep separate rows and profiles.
- Known mouse diagrams retain their arrows and clickable inline shortcut editors when additional controls are discovered. Point & Scroll sits below the diagram, and the footer aligns Uninstall Options+, permissions and Start at login.
- Quit Options+ appears only while Options+ is running. Removed redundant control instructions and unused hidden UI state.
- Coarse upper battery levels now say “High (approx.)”; “Full” is reserved for an explicit charge-complete report.
- Receiver discovery uses the paired mouse serial before waking it, preserving its profile and offline shortcut editors across helper restarts.

- The helper is explicitly marked as a hidden agent so MX Mouse stays out of Force Quit when Settings is closed. Verified in the macOS Force Quit dialog with the helper running.

- Opening Settings starts the helper before mouse discovery and automatically quits a conflicting Logi Options+ agent. Failures are reported.
- Installation detects helpers launched under their login-item identifier; Settings recognises a resident helper whose executable path disappeared during replacement.

- Restored M705 artwork, clickable button labels and connector arrows, including wheel tilt, using Options+ artwork and layout metadata.
- Remembered mice retain their last known layouts and editable shortcuts while offline, after receiver removal, and across Settings/helper restarts. Existing MX Master 3 installations receive a baseline layout until discovery refreshes it.
- The README distinguishes resident helper memory from the additional memory used only while Settings is open.

- Unsupported optional wheel or DPI settings no longer disable working button shortcuts.
- Failed receiver discovery retries automatically, even if the initial scan found no mouse. Wake and settings reload retry immediately.
- A sleeping or disconnected paired mouse shows as waiting and retains wake recovery, without repeatedly logging expected offline errors.
- Settings initially selects a connected mouse instead of the first offline pairing. Explicit selections remain stable.
- Receiver-slot replacements cannot receive cleanup writes intended for the previous mouse.

## Footprint and validation

The helper executable is **112,672 bytes**, **17,536 bytes larger** than the reconnect-fix baseline. It uses the same macOS frameworks, with no additional resident runtime or worker process. Persistent application state is 2,264 bytes per discovered mouse and 256 bytes per transport on arm64; framework and HID allocations are additional.

Earlier builds with one M705 active through Unifying and an additional MX Master 3 pairing offline measured helper physical footprint below **5 MiB**. Longer-running samples were 4.39 MiB; five samples of an earlier build with Settings closed were 3.05 MiB. This is a one-active-mouse result, not a two-mouse memory measurement.

Native tests pass with AddressSanitizer/UndefinedBehaviorSanitizer where applicable. Coverage includes receiver routing and replacement, actual MX Master 3S/4 control-table fixtures, independent gesture/Haptic bindings, reconnect and scan retries, profile isolation, device selection, unsupported controls, import and installation. The release ZIP is extracted and both app signatures, version numbers and architecture are verified before publication.

## Hardware limits

The new implementation has been checked for discovery, configuration and battery reporting on an older M705 (`101b`) through a Unifying receiver. MX Master 3 for Mac Bluetooth has hardware evidence from earlier builds. Physical button/scroll interaction, two simultaneously awake mice, MX Master 3S/4, Bolt, reconnect and sleep/wake testing remain incomplete for this release. The updated build also has discovery, configuration and coarse battery evidence for the newer M705 (`406d`) through Unifying, with MX Master 3 for Mac connected simultaneously.

Only features the helper implements are exposed. HID++ 1.0-only mice, older Gestures2 thumbwheels and alternative gaming-mouse control/DPI protocols require additional backends. See [coverage and verification tiers](https://github.com/ruibeard/logitech-options-plus-alternative/blob/v0.2.0/docs/development.md#capability-and-verification-tiers).

## Install

Updated v0.2.0 package: bundle build **8**, including sidebar and footer layout fixes, preserved inline shortcut editors, accurate coarse battery labels and receiver identity recovery for offline editing.

**Apple Silicon · macOS 13+**. Download the ZIP, unzip, and drag MX Mouse Settings into Applications. Quit Settings and gracefully stop its helper before replacing an older installation. Existing settings are preserved. See [upgrade instructions](https://github.com/ruibeard/logitech-options-plus-alternative/blob/v0.2.0/docs/setup.md).

Development-signed and **not notarized**; macOS may require Privacy & Security → Open Anyway. Grant permissions to the embedded MX Mouse Helper if requested, and quit competing mouse controllers first.

# MX Mouse v0.2.1 — Clearer keyboard shortcuts

## New

- Shortcut labels use the character that your current keyboard layout prints for the key. A key that the built-in table does not know is no longer shown as "Key N".
- The shortcut editor shows the key code below the shortcut.
- The key below Esc gets an orange warning. UK (ISO) and US (ANSI) keyboards give this key different codes (10 and 50). A shortcut recorded under one layout, or while a remap tool such as Karabiner-Elements runs, can fail under the other. The warning tells you to record the shortcut again.
- **Test** button next to each shortcut. It sends the shortcut after 2 seconds, so you can switch to the target app first. Test asks for Accessibility permission for MX Mouse Settings the first time.

## Fixed

- Code 50 was always shown as "`", and code 10 was shown as "Key 10". On a UK keyboard this made a wrong shortcut look correct and the correct shortcut look wrong.

## Install

**Apple Silicon · macOS 13+**. Download the ZIP, unzip, and drag MX Mouse Settings into Applications. Quit Settings and gracefully stop its helper before you replace an older installation. Existing settings are kept. See [upgrade instructions](https://github.com/ruibeard/logitech-options-plus-alternative/blob/v0.2.1/docs/setup.md).

Development-signed and **not notarized**. macOS can ask you to use Privacy & Security → Open Anyway.

# MX Mouse v0.1.1 — M705 + Unifying

## New

- **Logitech M705 through a Logitech Unifying USB receiver** (`046d:c52b`, paired mouse `101b`). Includes the older thumb-button variant.
- Model-specific settings with a real M705 image and thumb-button callout.
- Battery indicator when the mouse reports it: percentage or a coarse label.
- Clear selected/unselected control labels; no dashed focus outline.

MX Master 3 for Mac over direct Bluetooth remains supported. Saved settings are preserved; new thumb bindings default to native behavior.

## Install

**Apple Silicon · macOS 13+**. Download the ZIP, unzip, and drag MX Mouse Settings into Applications. Quit the existing Settings app and stop its helper before replacing an older installation. See the README setup link for upgrade steps.

Development-signed and **not notarized**; macOS may require Privacy & Security → Open Anyway. Use Set Up… to grant helper permissions if requested. Quit competing mouse controllers first.

## Limits and validation

M705 wheel tilt remains native; no M705 software DPI, SmartShift, or thumb-wheel controls. Bolt, other receiver models, and multiple simultaneous mice are unsupported. Options+ profile import remains specific to MX Master 3 profiles.

Live M705 discovery, capability queries, configuration, battery queries, and clean shutdown were checked. Full button/scroll interaction and sleep/wake testing remain incomplete. Automated parser, storage, receiver-pairing, importer, and installer checks pass. The packaged app's signatures are verified after ZIP extraction.
